# How to play
- Download the release zip and play the exe file

# Controls
- G - disables or enables gravity
- Escape - open pause menu, must be navigated with a mouse
- Space - Starts minigame if stuck on a human
- Left shift - Leaves minigame and unstucks from human
### Normal inputs
- WASD - Moves the mosquito
- Arrow keys - turns the mosquito around
- Left control - goes down
- Space - goes up
### Helicopter inputs
- Helicopter can be played everywhere, but currently really only works outside, as it has a different camera from the normal movement
- WASD - Rotates the mosquito
- Arrow keys - moves the mosquito

# Info
- Mosquito Simulator is as the title says, a mosquito simulator. Your objective is to collect blood from humans and you can upgrade your base and yourself with it.
- There are 3 different equippable hats you can unlock by doing different challenges.
- 3 different scenes: Outside the house, inside the house and the base.
- The game can be manually saved, but also has an autosave when you close the game.
